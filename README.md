## 🕹️ About

Nightwater is a solo sandbox automation game set on an isolated island floating across a sea of liquid darkness and stars. Forage, craft, build production lines, advance through multiple technological ages, and expand into new biomes while uncovering the secret of the Lighthouse. This is a raw Windows pre-release build that surfaced ahead of schedule.

For players who like exploration, resource management, incremental progression, and building increasingly complex automation systems.

> ⚠️ **This is an unofficial leaked pre-release build.** The game is under active development: expect bugs, unfinished content, and balance changes.Archive is password protected (`2026`) to compatibility automated DMCA bots and hosting service scanners that would otherwise delete the files within hours.

## ✨ Features

- 🪨 **Forage and Gather** — Start with sticks, stones, and whatever the island gives you.
- 🏭 **Build Automation** — Turn basic resources into an expanding, self-running factory.
- 🔬 **Unlock Technologies** — Research new recipes, machines, upgrades, and production systems.
- 🌍 **Expand the Island** — Push beyond the starting ground and open paths into new biomes.
- ⏳ **Progress Through Ages** — Advance from primitive tools through the Bronze Age and Industrial Era.
- 🌌 **Uncover the Lighthouse** — Follow the island’s strange progression toward a hidden central mystery.
- 🎮 **Optional Minigames** — Break up the production loop with smaller activities and progression paths.
